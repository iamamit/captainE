# 19 · IP and license audit

*2026-10-15. A technical audit, not legal advice. Have a lawyer confirm the open points before a commercial
release.*

## What was checked

1. **Own code**
   - All 194 tracked files: copyright and license headers.
   - Notes such as "ported from", "copied from" or "adapted from".
   - References to GPL editors (Kdenlive, Shotcut, Olive, Natron, OpenShot, Blender).
2. **Git history**
   - Every blob ever committed, checked for media, fonts, LUTs and native libraries.
3. **Dependencies**
   - The license of each of the 497 third-party crates in `Cargo.lock`, read from `cargo metadata`.
   - Which of them actually ship in the programs (484) and which are test-only.
4. **Names**
   - Other companies' product and feature names in the UI and the code (Adobe, Blackmagic, Apple, Avid,
     Microsoft/GitHub).
5. **Tools run at runtime**
   - FFmpeg and its encoders (x264/x265), Rubber Band, VST3, Whisper, Apple Vision.

## Findings

| Area | Result |
|---|---|
| Copied code | None found. No foreign copyright headers. No porting notes. The algorithms (box/Gaussian blur, Fritsch–Carlson curves, EBU R128 loudness, bilinear sampling, unsharp mask) are textbook methods written from scratch. |
| History | Clean. No media, fonts, LUTs or binaries were ever committed. The only images are captainE's own screenshots, rendered offscreen with synthetic test footage. |
| Crate licenses | All permissive: MIT, Apache-2.0, BSD, ISC, Zlib, Unicode, BSL-1.0 and CDLA-Permissive. The exceptions are below. |
| MPL-2.0 | `option-ext`, used through `clack-finder` for CLAP plugin discovery, and `colored`, test-only. MPL is file-level copyleft: using these crates unmodified is fine, and their source is public on crates.io. |
| Fonts | `epaint_default_fonts` ships Ubuntu (Ubuntu Font Licence), Hack (MIT/Bitstream), Noto Emoji and Emoji Icon (OFL). These licenses allow bundling, provided the license texts go with the app. |
| Dual-licensed GPL | `Apache-2.0 OR GPL-2.0-only` and `MIT OR Apache-2.0 OR LGPL`: captainE takes the permissive option. |
| FFmpeg, x264, x265 | Run as a **separate program** installed on the user's computer. They are not linked or bundled (`tools/bundle.sh` copies only captainE and its Python helper), so their GPL does not reach captainE. **If FFmpeg is ever bundled**, use an LGPL build without x264/x265, or license x264 commercially. See doc 11. |
| Rubber Band, VST3 | Not used. Audio plugins use CLAP (MIT). |
| Codec patents | H.264/HEVC encoding currently goes through the user's own FFmpeg (libx264/libx265). For a commercial build, default to VideoToolbox (`hevc-hw`, which Apple licenses) and keep x264 as an option. See doc 11. |
| AI | Claude runs through the user's own key or the `claude` CLI. Whisper models are MIT. Vision uses Apple's on-device framework. Nothing is bundled. |
| Product and feature names | **Fixed:** "Auto Reframe" (Adobe Premiere's feature name) is now "Reframe for…". **Fixed:** "Copilot" (a Microsoft/GitHub trademark) is now "CoCaptain" everywhere, and the doc screenshots were regenerated. The code and docs keep comparative mentions ("like Premiere", "Final Cut Pro XML" export, which is Apple's published interchange format). Nominative use like this is normal; keep other companies' names and logos out of marketing and branding. |
| UI look | The layout (media pool, viewer, inspector, timeline) is the common NLE arrangement. The look comes from your own mockup. No Adobe or Blackmagic artwork, icons or skins. |

## Done in this pass

- `THIRD_PARTY_NOTICES.txt` lists all 484 shipped components with their license texts. It is generated by
  `python3 tools/third_party_notices.py`; re-run it after dependency changes. `tools/bundle.sh` copies it into the
  app.
- The feature name "Auto Reframe" was renamed, and the doc screenshots were regenerated with the current UI.

## Still open (your decisions)

1. **Choose captainE's own license and add a `LICENSE` file.** Without one, the code is "all rights reserved",
   which is fine while the repo is private. If it goes open source, MIT/Apache is the simplest choice given the
   all-permissive dependencies. Then set `license = "…"` in `Cargo.toml`. Doc 11 lists the trade-offs.
2. **Trademark search** for "captainE" and "CoCaptain" before a public launch. A quick check of the USPTO and
   EUIPO databases and the domain names.
3. **Export default for a commercial build:** VideoToolbox rather than x264. See codec patents above.
4. **The codit and Resolve integration** is a separate repo that uses Blackmagic's public scripting API.
   Using that API is fine; do not ship Blackmagic SDK files or names as part of captainE.
