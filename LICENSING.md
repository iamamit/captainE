# captainE: licensing and costs

*Last reviewed 2026-10-15. This is a technical summary, not legal advice. Have a lawyer confirm it before you
sell captainE. The full audit is in [docs/19-ip-and-license-audit.md](docs/19-ip-and-license-audit.md). The
license text of every shipped library is in [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt), regenerated by
`python3 tools/third_party_notices.py`.*

## What you pay

| Cost | Needed? | Notes |
|---|---|---|
| **Apple Developer Program, $99/year** | **Only when you publish for Mac users** | Signing and notarizing removes macOS's "unverified developer" warning. You can skip it for a beta and have testers use *Privacy & Security → Open Anyway*. The same membership covers the Mac App Store, where Apple also keeps 15% of sales (30% above $1M a year). |
| Everything else in this file | **No** | Open-source or built into macOS: free to use, free to ship with the license notices included. |
| *Optional:* trademark filing | Your choice | About €290 for Germany (DPMA), €850 for the EU (EUIPO) or $350 for the US, per class. Protects the names "captainE" and "CoCaptain". |
| *Optional:* Windows code signing | Only for a Windows release | $100–400/year. Unsigned apps show a SmartScreen warning. |
| *Optional:* lawyer review | Recommended before charging money | One-off. |
| *Optional:* GitHub Actions minutes | Only if a **private** repo exceeds the free monthly minutes | macOS runners count 10× against the allowance. Public repos are free. |
| *Watch out:* AI usage | Only if **you** pay for users' AI | Right now CoCaptain uses each user's own Claude login or API key, so it costs you nothing. |

**Rules that keep it free:**

1. Don't bundle FFmpeg built with x264/x265 (see *Video* below).
2. For a paid version, export H.264/HEVC through Apple's VideoToolbox.
3. Keep the license notices in the app.

## Tools and libraries captainE uses

### Video, audio and media (run as separate programs on the user's Mac)

| Tool | What captainE uses it for | License | Why there's nothing to pay |
|---|---|---|---|
| **FFmpeg / ffprobe** | Decoding all footage; encoding exports; proxies; thumbnails; probing files | LGPL-2.1+ (GPL-2+ when built with GPL parts) | captainE **runs** the copy the user installed (Homebrew or similar). It does not link it or ship it, so its license puts no obligation on captainE. If you ever bundle it, use an LGPL build without x264/x265 and include its license and source offer. |
| **x264 / x265** (inside the user's FFmpeg) | H.264 / HEVC export encoding | GPL-2+ (commercial licenses exist) | They are part of the user's FFmpeg, not part of captainE. For a commercial release, make **VideoToolbox** the default H.264/HEVC encoder (already available as `hevc-hw`): Apple has licensed those codec patents. |
| **VideoToolbox** (macOS) | Hardware decoding of 4K footage; hardware HEVC export | Part of macOS | A system framework that every Mac app may use. Apple pays the H.264/HEVC patent royalties for it. |
| **Core Audio** (macOS, through `cpal`) | Audio playback and the meters | Part of macOS | System framework. |

### AI features

| Tool | Use | License | Why there's nothing to pay |
|---|---|---|---|
| **Claude** (Anthropic), through the user's `claude` CLI login or their own API key | CoCaptain's reasoning | Anthropic's terms of service (commercial) | Each user brings their own Claude access, so you pay nothing. If you ever pay for users' AI yourself, you pay per use. |
| **mlx-whisper** (Apple's MLX examples) and the **OpenAI Whisper** model weights | Speech-to-text for captions, filler-word removal, edit-by-transcript | MIT (code and weights) | Open source and runs on the user's Mac. Not bundled today. |
| **MLX** (Apple) | Runs Whisper on Apple Silicon | MIT | Open source. |
| **Apple Vision framework**, called through **PyObjC** and **Python** | Removing backgrounds, tracking subjects, reframing | macOS framework; PyObjC MIT; Python PSF license | System framework plus open-source glue. `vision.py` is captainE's own code. |

## captainE's own code, names and design

- **Code:** written for this project. No code was copied from Adobe, Blackmagic, Apple or GPL editors
  (see doc 19). The algorithms used are standard published methods.
- **captainE's own license:** **not chosen yet.** Without a `LICENSE` file the code is "all rights reserved",
  which is fine while the repo is private. Add one before publishing the source.
- **Names:** "CoCaptain" replaced "Copilot", a Microsoft/GitHub trademark. "Reframe" replaced Adobe's "Auto
  Reframe". Do a free trademark search for "captainE" and "CoCaptain" before launch.
- **Design:** your own mockup and the standard editor layout. No Adobe or Blackmagic icons, skins or artwork.
- **Mentions of other products** (in the docs, and Final Cut XML export) are descriptive comparisons. Keep their
  names and logos out of marketing.
